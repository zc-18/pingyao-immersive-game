# 优化 AI提示词-APP版.md 文档计划

## Context（背景）

用户需要优化 `AI提示词-APP版.md` 文档，使其更适合每次新开对话时复制粘贴给 Claude Code。当前文档存在以下问题：

1. **第 0 轮已完成但未标记**：3d-test 页面、renderjs 集成、Three.js 本地化已完成，但文档中未明确标注
2. **图片资源状态不明确**：`img/` 目录下的图片尚未移动到 `static/img/`，但文档中假设已存在
3. **新对话上下文缺失**：每次新对话时 AI 需要从零理解项目，但文档中缺少"必读文件清单"和"快速理解项目"部分
4. **进度追踪不直观**：已完成的轮次需要更明显的标记
5. **图片使用说明分散**：图片路径约定、命名规则、使用原则散落在多处

根据项目探索结果：
- ✅ 第 0 轮已完成 90%（3d-test 页面运行正常，但缺少 `common/3d/` 架构目录）
- ❌ 图片资源未迁移（`img/` → `static/img/`）
- ✅ 数据层完整（6 个 mock 数据文件）
- ⚠️ 街景页仍使用 CSS 伪 3D（未迁移到 Three.js）

## 优化目标

1. **明确标记第 0 轮完成状态**，添加"已完成但需补充"的说明
2. **统一图片资源说明**，在文档开头集中说明图片当前位置和使用约定
3. **增强新对话引导**，在每轮提示词开头添加"新对话必读"部分
4. **优化进度追踪**，使用更直观的符号（✅ ⏸️ ⬅️ ⏭️）
5. **精简冗余内容**，合并重复的项目背景说明
6. **添加快速检查清单**，帮助 AI 快速验证项目状态
