# 水墨地图与腾讯位置服务混合接入设计

## 目标

保留现有水墨游戏地图作为地图页的主视觉，同时接入手机真实 GPS 和可选的腾讯位置服务，让地图页能够显示玩家现实位置、当前位置地址、真实 POI 和步行路线。没有腾讯 Key 或后端代理时，水墨地图仍可正常使用。

## 已确认的范围

- 现有水墨地图继续作为默认地图，不替换为腾讯底图。
- 地图页使用 `uni.getLocation({ type: 'wgs84' })` 获取一次当前位置，在本地换算为 GCJ02 后投影，并在页面显示定位状态。系统定位只输出 WGS84，直接请求 `gcj02` 需要在 manifest 中配置地图厂商 SDK/Key，未配置时会失败，因此统一采用本地换算，各端均无需 Key。
- 通过 `uni.startLocationUpdate` 或持续监听不作为首版必需能力，首版先提供手动刷新定位，避免后台定位权限和电量问题扩大范围。
- POI 数据增加可选的 `location` 字段，统一使用 GCJ02 的 `latitude`、`longitude`。
- 根据平遥古城的真实坐标范围，把当前位置和 POI 坐标投影到现有水墨地图的百分比坐标系。
- 腾讯接口封装为独立适配层，首版覆盖逆地址解析、地点搜索和步行路线请求；Key 为空时不发请求。
- 腾讯 WebService 请求默认通过配置的代理地址发送，前端不保存 SecretKey；开发验证可以显式配置直连地址，但不作为生产默认值。
- 现有 `userProgress.steps` 继续表示游戏内摇杆移动步数。真实 GPS 距离另存为独立运行时数据，不参与现有任务、经验和等级结算。
- 首版不实现真实手机计步器接入、不改 3D 摇杆、不接腾讯真实地图底图 SDK。

## 数据流

```text
地图页
  ├─ 定位按钮
  │    └─ uni.getLocation(wgs84) → 本地换算 GCJ02
  │          ├─ 写入运行时定位快照
  │          └─ 将经纬度投影为水墨地图百分比位置
  ├─ 当前坐标
  │    └─ 腾讯适配器（配置代理和 Key 时）
  │          ├─ 逆地址解析 -> 地址文本
  │          ├─ 地点搜索 -> 周边 POI
  │          └─ 步行路线 -> 距离、时间、路线点串
  └─ 本地 POI
       └─ location(GCJ02) + mapPosition(游戏地图)
```

## 模块边界

### `common/utils/location.js`

负责调用 uni 定位 API、校验坐标和保存/读取运行时定位快照。输出标准结构：

```js
{
  latitude: Number,
  longitude: Number,
  accuracy: Number,
  speed: Number,
  heading: Number,
  timestamp: Number,
  source: 'device'
}
```

定位失败只返回可展示的错误信息，不覆盖上一次有效定位。

### `common/utils/tencent-lbs.js`

只负责构造和发送腾讯服务请求，不直接修改页面状态。接口包括：

- `reverseGeocode(location)`：坐标转地址
- `searchNearby(keyword, location)`：周边地点搜索
- `walkingRoute(from, to)`：步行路线

当 `key` 或代理地址缺失时返回 `disabled` 状态；HTTP、腾讯业务状态码和解析错误统一转换为可判断的错误对象。代理请求不把 SecretKey 发送到客户端。

### `common/data/poi-list.js`

为已知景点增加真实 GCJ02 坐标；没有确认坐标的 POI 保持无 `location`，不能伪造精确位置。地图投影仍使用现有 `mapPosition`，直到完成真实坐标校准。

### `pages/map/map.vue`

负责定位按钮、定位状态、玩家真实位置投影、地址展示和路线入口。页面只消费定位与腾讯适配器的结果，不在组件内拼接腾讯 URL。

## 坐标投影

首版使用平遥古城范围的经纬度包围盒，将经度映射到水墨地图横坐标，将纬度反向映射到纵坐标。投影前进行边界裁剪，避免 GPS 漂移将玩家标记绘制到地图外。包围盒和边距集中放在 location 工具中，后续可用实测轨迹校准。

## 错误和降级

- 用户拒绝定位权限：保留静态“我在此”位置，提示开启定位权限。
- H5 无定位或浏览器拒绝：显示定位不可用，不影响水墨地图。
- 腾讯 Key/代理未配置：显示“腾讯服务未配置”，不发网络请求。
- 腾讯请求失败或超额：保留 GPS 标记，地址和路线显示不可用状态。
- 坐标精度大于 100 米：显示低精度提示，不触发精确 POI 路线行为。

## 安全与配置

Key、代理地址和是否启用腾讯服务通过运行时配置读取，不提交真实密钥。生产环境应使用后端代理和腾讯商业授权；本地 H5 验证只允许使用受限测试 Key。

## 验证标准

- 单元测试覆盖坐标校验、包围盒投影、腾讯配置缺失降级和路线响应解析。
- 现有街景步数逻辑和现有测试不受影响。
- H5 构建通过；没有配置腾讯服务时地图页仍能打开并显示静态 POI。
- 定位成功时玩家标记从固定街景点切换为 GPS 投影位置，定位失败时回退到静态位置。
