# 3D 角色与街景精细化验证

2026-09-07，本轮修改以街景实际 renderjs 实现为主。参考 meow.flyfish.dev 的近景构图、柔和照明、昼夜变化和物件交互；未复制其模型、纹理或代码。

## 角色与场景

- 新角色 `pingyao-hanfu-detailed.glb`：1,687,760 bytes，含隐藏服饰变体共 31,344 三角面、46 个材质或服饰选择分组。原始 KayKit CC0 骨架保留五段动画，可见网格重新生成。
- 面部、头发、交领、袖口、手指、腰结、裙褶、布鞋和配饰增加建模细节。袖根跨胸部和上臂平滑蒙皮；裙摆跨髋部和大腿混合。运行时增加眨眼、轻微衣摆形变、动作权重过渡与接地阴影。
- 移动以实际位移驱动动作；静止时不会提前覆盖致意。建筑、台阶、摊位和行人有碰撞响应，相机遇到实体表面会回缩。弹窗期间暂停移动；场景重建同步控制状态。
- 四种时辰平滑切换天空、灯光、雾、窗纸和灯笼。使用生成式 1K 青石纹理、织物细纹与更细的砖面纹理；图片来源与完整提示词见 `static/textures/README.md`。
- 新增漫步/快行、观衣、缩放、归位和致意控制，兼容现有逻辑层与 renderjs 桥接。

## 性能与边界

MX450 / ANGLE D3D11，844x390、像素比 0.85、阴影被自适应策略关闭的五秒采样：53.55 FPS，P95 33.3 ms，200 次绘制调用，89,473 三角面。该短采样不是稳定 60 FPS 或手机性能承诺。SwiftShader 软件渲染采样约 1.13 FPS，首轮着色器编译也较慢。

自动化记录到现有音频缺失错误；`static/audio/` 尚未配齐声音文件。此次没有接入真实 GPS、支付或后端。Android/iOS APP WebView、资源路径、手势区、温升、持续运行和后台恢复仍需 HBuilderX 真机验证。衣摆使用蒙皮与形变近似，未实现完整布料物理仿真，不能保证任意姿态下所有服饰表面绝无交叠。
